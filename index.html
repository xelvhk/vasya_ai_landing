PRODUCT VALUE

Не витрина LLM. Рабочий desktop assistant.

Vasya AI превращает голос и текст в конкретные действия: добавить задачу, создать событие, найти контекст в памяти, продиктовать текст, выгрузить заметку в Obsidian или синхронизировать проектные обновления в Notion.

Ядро остается локальным: SQLite, локальные файлы, Ollama, faster-whisper и TTS backend. Google Calendar, Notion и GitHub подключаются поверх через изолированные адаптеры.

DESKTOP SHELL

Click-to-talk, hotkey и понятные состояния.

Плавающий avatar widget, tray/menu bar control, быстрый текстовый ввод и voice loop делают Васю доступным без терминала.

SYSTEM DESIGN

Локальное ядро, модульная маршрутизация, безопасные границы.

INPUT voice / text
ROUTING orchestrator
AGENTS task / calendar / note / game
SERVICES repositories / adapters
OUTPUT text / voice / API

Core orchestration не зависит от UI и транспорта. Интеграции входят через сервисы и адаптеры, а API защищен auth, throttling и redaction для чувствительных логов.

SECOND BRAIN

Память, которую можно проверить.

Memory Center построен как inspectable local foundation, а не черный ящик. Источники, чанки, синхронизация и daily digest имеют provenance и локальные Markdown-артефакты.

  • Поиск по локальному контексту и quick-open файлов или URL.
  • Daily digest с историей за today, yesterday, 7d и 30d.
  • Obsidian, Notion и GitHub sync через явные adapter boundaries.

CURRENT RELEASE

v0.6.0: быстрее к первому полезному ответу.

Утренний брифинг собирает погоду, задачи, события и Memory Center в один daily-flow.

macOS setup идет через `scripts/setup_mac.sh` и не перезаписывает существующий `.env`.

`doctor` проверяет Python, virtualenv, зависимости, Ollama, TTS, storage, API auth и optional integrations.

FIRST RUN

Пять команд до локального запуска.

git clone https://github.com/xelvhk/vasya_ai.git
cd vasya_ai
bash scripts/setup_mac.sh
source .venv/bin/activate
ollama pull llama3
python scripts/doctor.py
python main.py

Setup готовит `.venv`, зависимости, локальный `.env`, storage, memory wiki и voices.

Опциональный API режим: `python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8787 --reload`.
