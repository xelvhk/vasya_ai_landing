Vasya AI собирает голос, память, задачи, календарь и локальные артефакты в одну понятную систему. Фокус не на магии, а на проверяемом пути от команды до результата.

01

Голосовой цикл команд

Hotkey, recorder, speech-to-text, routing policy и быстрые голосовые ответы.

02

Память с provenance

Поиск по локальному контексту, дайджесты, recent artifacts и понятные границы источников.

03

Интеграции как адаптеры

Obsidian, Notion, GitHub и календарные сценарии живут отдельно от ядра ассистента.

Один экран для ежедневного потока: сказать, уточнить, сохранить, выполнить.

Утренний брифинг, напоминания, диктовка, заметки и интеграционные обновления спроектированы как обычные рабочие пути, а не demo-only tricks.

Запуск должен быть таким же ясным, как первый ответ Васи.

Clone, setup, doctor, model pull and first run. Минимум ceremony, максимум проверяемости.

подготовка Setup

Собирает окружение и локальные файлы без перезаписи существующего `.env`.

проверка Doctor

Проверяет зависимости, storage, модель, TTS и интеграции перед первым запуском.

первый ответ First run

Запускает ассистента и показывает первый рабочий путь без ручной сборки контекста.

git clone https://github.com/xelvhk/vasya_ai.git
cd vasya_ai
bash scripts/setup_mac.sh
source .venv/bin/activate
ollama pull llama3
python scripts/doctor.py
python main.py
